改定日: 2026年7月23日

Sakamichi Blog PDF（以下「本アプリ」）は非公式アプリです。 各グループ、所属事務所、公式サイト運営者とは関係ありません。

1. 本アプリが扱う情報

本アプリは、利用者の氏名、メールアドレス、連絡先などを独自のサーバーへ送信・保存しません。 選択したブログ情報、生成したPDFおよびZIPはアプリまたはブラウザ内で処理され、 利用者が共有または保存先を選択した場合にのみ端末外へ出力されます。

2. 公式サイトへの接続

ブログ一覧と本文を取得するため、日向坂46、櫻坂46、欅坂46、乃木坂46の 各公式サイト、または本アプリが運用する取得用APIへ通信します。 公式サイトへの通信では、各公式サイトのプライバシーポリシーおよび利用条件が適用されます。

3. 広告配信

本アプリは広告配信のためGoogle AdMobを使用します。 Google Mobile Ads SDKは、IPアドレス、利用状況、診断情報、広告識別子、 おおよその位置情報などを収集する場合があります。 収集・利用の詳細は Googleプライバシーポリシー および Google Mobile Ads SDKのiOS向けデータ開示 、 Google Mobile Ads SDKのGoogle Play向けデータ開示 をご確認ください。

地域や設定に応じて、広告に関する同意画面またはトラッキング許可画面が表示されます。 許可しない場合でも本アプリのブログ取得・PDF保存機能を利用できます。 対象地域では、アプリ内メニューから広告のプライバシー設定を変更できます。

4. コンテンツと保存データ

公式ブログの文章・画像等の権利は、それぞれの権利者に帰属します。 本アプリで作成したファイルは、各公式サイトの利用条件および著作権法に従い、 個人利用の範囲でお取り扱いください。

5. 改定

法令、サービス内容または利用するSDKの変更に応じて、本ポリシーを改定する場合があります。 改定後の内容はこのページで公開します。

6. お問い合わせ

本アプリに関するお問い合わせは GitHub Issues からお願いいたします。
